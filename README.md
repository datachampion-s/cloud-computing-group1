# DCS HPC — Cloud Computing Group 1

This public repository documents the architecture and course deliverables for DCS HPC, a proposal-based platform that currently offers free, time-limited cloud GPU access for student research.

It is a documentation-only handover. The application implementation, operational credentials and deployment configuration are maintained separately and are not included here. No live resource IDs, passwords, keys, access tokens, private links or student records are needed to understand the design.
